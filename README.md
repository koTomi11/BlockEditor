Ezzel a szerkesztő programmal hatékonyan lehet 3D világot szerkezteni felülnézetből. 
A tervek szerint blokokra lenne a teljes pája felosztva amiknek a szerkeztésével egy teljes értékű 3D világ hozható létre,
és .map formátumba exportálható. A program kihasználja hogy a legtöbb utca vagy épület alaprajza szögletes,
ezért ezzel a blokkos rendszerrel valójában kis áldozatot kell hozni a nagy egyszerűség érdekében. A projekt elfog készűlni konyvtár formátumba is,
hogy akárki a saját projektjéhez hozzáfűzve generálhassa a saját világát.
